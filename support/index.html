Is het echt gratis?

Ja! BlockRacers is gratis en je kunt niets kopen.

Op welke apparaten kan ik spelen?

In je browser, op telefoon, tablet of computer. Zet de game als icoon op je beginscherm. Touchscreen werkt. Een controller is nog niet getest.

Hoe start ik?

Maak gratis een account. Is er nog plek in de beta? Dan word je automatisch goedgekeurd en klik je op je account-pagina op Speel nu. Een code invullen hoeft niet. Maak je avatar, check je garage en rijd door Parkstad en Beekdaelen. Je voortgang wordt opgeslagen.

Is het veilig voor mijn kind?

BlockRacers is gemaakt voor kinderen. Er is geen vrije chat, alleen vaste berichten. Geen reclame en geen trackers van derden. Zie je iets wat niet klopt? Meld het in de game. Meer op Ouders en privacy.

Hoe meld ik een bug?

Gebruik de meldknop in de game en kies 'bug'.
