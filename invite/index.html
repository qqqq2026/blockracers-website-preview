Zo werkt het

Onder 16? Je geeft ook het e-mailadres van je ouder. De invite gaat naar je ouder, die beslist of je mag meedoen. Meer vragen we niet: geen naam, geen adres, geen telefoonnummer.

  • 1. Maak gratis een BlockRacers-account. Dat kan iedereen met een e-mailadres.
  • 2. Bevestig je e-mailadres met de code uit de mail.
  • 3. Is er nog plek? Dan word je automatisch goedgekeurd. Je ziet Goedgekeurd op je account-pagina en klikt op Speel nu. Een code invullen hoeft niet.
  • 4. Zijn de 200 plekken vol? Dan sta je op de wachtlijst.
